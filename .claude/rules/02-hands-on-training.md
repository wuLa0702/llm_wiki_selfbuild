# 手写训练开发纪律

> 2026-07-22 确立。核心原则：关键逻辑手写理解，样板代码AI提速。

## 核心理念

**AI案例 → 删除全部代码 → 凭理解重新手写复现**

AI 案例充当"参考图纸"帮你快速看懂实现思路；删除代码重写 = 强制把「逆向读懂」转化为「正向构建」。

⚠️ 硬性规则：核心状态机逻辑不能边看边抄；先理解整体流程，再关闭案例独立编码。

---

## 一、必须优先手写（学习阶段）

**判定标准**：代码承载当前阶段核心思维模型，写错 = 概念理解不到位。

### 适用范围（LangGraph Agent 学习路线）

1. **Graph 核心骨架**
   - State 结构定义（TypedDict / Pydantic）
   - 节点函数、入参、状态读写逻辑
   - `add_node` / `add_edge` / `add_conditional_edges` 链路编排
   - 循环终止条件、分支判断逻辑

2. **核心机制 Demo**
   - Checkpointer 持久化、会话断点恢复
   - Human-in-the-loop 人工中断、resume 恢复
   - 原生多智能体消息传递、主管-工人路由逻辑

3. **基础工具调用、ReAct 循环逻辑**

4. **数据流规则**：状态覆盖、消息追加、历史管理

### 简单判断口诀

> 这块代码是 LangGraph 状态流转的核心，如果让你口头描述执行流程讲不清楚 → 一定要手写训练。

**目标**：做到脱离 AI，可以从零搭出最简可运行 Graph。

---

## 二、放心交给 Vibe Coding

**判定标准**：业务样板、胶水代码、配置、第三方集成，不涉及智能体核心调度逻辑。

**清单**：
1. 各类模型初始化代码（OpenAI / Ollama / Claude 封装）
2. LangSmith 环境配置、日志、回调样板
3. 异常捕获、重试装饰器、通用工具包装函数
4. 接口适配：对接 Agent Chat UI SSE、FastAPI 封装
5. 文件读写、向量库连接、RAG 通用检索函数
6. 格式化 Prompt 模板、输出解析器样板
7. 依赖管理、Dockerfile、启动脚本、环境变量加载
8. 复杂通用工具（爬虫、代码沙箱等外围能力）

**特点**：逻辑固定、模板化，不改变 Agent 执行流程；就算 AI 写，也不会影响对状态机核心的理解。

---

## 三、混合模式（AI 生成骨架，自己重写核心）

适合中等复杂度项目（如完整多智能体协作系统）。

**操作规范**：
1. AI 生成整体项目结构
2. **删除 Graph 构建、State、节点流转代码**
3. 由你独立手写智能体调度核心
4. 外围接口、配置、工具封装直接复用/微调 AI 代码

---

## 四、落地执行简易判断流程

```
准备写一段代码
  ├── 属于 LangGraph 核心调度逻辑？(State/节点/边/分支/循环/多智能体路由)
  │     └── 是 → 看懂思路，清空代码，独立手写实现
  │
  └── 否 → 属于样板胶水/第三方集成/配置代码？
        ├── 是 → Vibe Coding 生成，逐行审查、按需修改
        └── 灰色复杂项目 → AI 生成外围骨架，核心 Graph 代码自己重写
```

---

## 五、个人执行纪律

1. **所有新知识点的第一个 Demo，强制手写**
   - 第一次写条件分支、第一次写人在回路、第一次主管工人多智能体
   - 不允许直接拿完整 AI 代码

2. **同一个模式成功手写复现 1~2 次之后**
   - 后续同类场景放开使用 Vibe Coding 提速
   - 只重点把控核心逻辑
