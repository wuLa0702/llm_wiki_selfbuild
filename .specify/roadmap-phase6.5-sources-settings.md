## 一、资料源界面

### 1.1 布局

```
┌──────┬────────────┬──────────────────────────────────────────┐
│ Icon │  资料源     │  文件预览 / 详情                          │
│ Bar  │  文件夹树   │                                          │
│      ├────────────┤                                          │
│      │ ▼ 子目录1  │  [导入文件] [导入文件夹]                   │
│      │   📄 a.md  │                                          │
│      │   📄 b.md  │  =======================================  │
│      │ ▼ 子目录2  │                                          │
│      │   📄 c.md  │  预览区域：选中文件后展示内容+元数据         │
│      │            │  右侧：🗑删除  📝提取到Wiki                │
│      │            │                                          │
│      ├────────────┤                                          │
│      │ 统计信息    │                                          │
└──────┴────────────┴──────────────────────────────────────────┘
```

### 1.2 后端改动

| API | 方法 | 说明 |
|-----|:----:|------|
| `/v1/sources/tree` | GET | 返回 `raw/sources/` 的目录树（含文件夹层级） |
| `/v1/sources/{path}` | DELETE | 删除单个文件，同时删 DB 中 `source_file` 匹配的 wiki 页面 |
| `/v1/sources/folder/{path}` | DELETE | 级联删除文件夹及所有子文件，级联删除关联 wiki 页面 |
| `/v1/sources/extract-to-wiki` | POST | 大文件 LLM Agent 多页面提取（异步任务） |

级联删除逻辑：
```
删文件 → 查 DB wiki_pages 表 source_file = 此路径
       → 删 wiki/{path}.md
       → 删 DB wiki_pages 记录
       → 删 DB page_links 中涉及此页的记录
```

### 1.3 前端改动

| 文件 | 改动 |
|------|------|
| `templates/sources.html` | 重写为文件夹树 + 预览区布局 |
| `static/js/base.js` | 新增 `loadSourcesTree()`, `deleteFile()`, `deleteFolder()` |
