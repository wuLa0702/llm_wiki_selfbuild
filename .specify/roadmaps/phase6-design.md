# Phase 6 — UI 美化设计方案

> **日期**：2026-07-09
> **标定**：生产化体验阶段 —— 在 API 完整的基础上，让 Wiki 浏览体验达到可展示水平
> **前置依赖**：Phase 3-5 全部完成（核心功能 + 搜索 + API）
>
> ⚠️ **修正说明**：本文档源自原名 "Phase 5 — 前端设计方案"（标题误导）。已根据 roadmap.md Phase 6 定义重新校正：**当前是 Phase 6（UI 美化），Phase 5 为搜索增强阶段**。布局方案也从图标侧栏方案修正为顶层文档中的顶部导航+左侧边栏方案。

---

## 一、设计原则

1. **不碰后端逻辑** — 只做前端/静态层美化，不改 API、不重构核心
2. **增量改造而非推翻重来** — 当前模板各自独立（内联 CSS），迁移到 Jinja2 继承体系，不改路由注册方式
3. **每个界面必须覆盖三态** — 加载态、空态、错误态
4. **暗色模式为默认** — 参考 nashsu 深色主题，同时支持亮色切换，localStorage 持久化
5. **零构建步骤** — 纯 CSS + 服务端模板，不需要 webpack/vite
6. **移动端适配** — 面试官可能用手机打开

## 二、整体布局

### 2.1 布局结构

根据 roadmap.md 的设计，采用 **顶部导航栏 + 左侧边栏 + 主内容区** 的三段布局：

```
┌──────────────────────────────────────────────────────────┐
│  顶部导航栏：Logo | 导航链接 | 搜索框 | 暗色切换           │  ← 56px
├──────────┬───────────────────────────────────────────────┤
│ 左侧边栏  │  主内容区                                    │  ← flex-1
│  (240px)  │                                              │
│          │  [各页面视图，根据路由切换]                      │
│ 📁 知识树 │  /wiki           → Wiki 首页                  │
│ 📦 资料源  │  /wiki/{path}    → 页面渲染                  │
│ 🔍 搜索   │  /wiki/query     → 知识问答                  │
│ 🕸️ 图谱   │  /wiki/graph     → 知识图谱                  │
│ ⚙️ 批量导入│  /wiki/sources   → 资料源                    │
│          │  /wiki/queue      → 活动面板                  │
│          │  /wiki/import     → 批量导入                  │
├──────────┴───────────────────────────────────────────────┤
│  底部活动栏：最近操作 | ingest 进度条（折叠式）             │  ← 自动隐藏
└──────────────────────────────────────────────────────────┘
```

### 2.2 与 roadmap.md 的布局一致性

| 布局元素 | roadmap.md 要求 | 本方案 |
|----------|----------------|--------|
| 顶部导航 | ✅ Logo + 搜索框 + 暗色切换 | ✅ 增加导航链接（首页/图谱/资料源/队列） |
| 左侧边栏 | ✅ 实体/概念/来源三级目录树，hover 展开子项 | ✅ 260px，可折叠，移动端隐藏 |
| 主内容区 | ✅ flex-1 自适应 | ✅ flex-1 自适应 |
| 底部活动面板 | ✅ 实时 ingest 进度条 | ✅ 折叠式，默认收起 |

### 2.3 与 nashsu 的关键差异

| 维度 | nashsu（桌面应用） | 我们（Web） | 理由 |
|------|-------------------|------------|------|
| 布局 | 三列可拖动 | **两列（边栏+内容）** | Web 屏幕水平空间有限 |
| 导航 | 图标侧栏 + 知识树 | **顶部导航 + 左侧边栏** | Web 用户习惯，边栏可折叠 |
| 编辑器 | 双栏 Markdown 编辑 | **不提供编辑** | 当前 LLM 只写不编辑 |
| 图谱 | sigma.js (WebGL) | **vis.js (Canvas) — 已有实现** | 替换成本高，优先增强交互 |
| 移动端 | 不支持（桌面应用） | **响应式支持** | Web 必须 |
| 研究面板 | 右侧独立列 | **不做** | 功能范围不同 |

## 四、顶部导航栏（56px）

```
┌───────────────────────────────────────────────────────────────┐
│  [✦] LLM Wiki   [首页] [图谱] [资料源] [队列] [导入]   [🔍 ██] [🌙]  │
└───────────────────────────────────────────────────────────────┘
```

| 区域 | 内容 | 交互 |
|------|------|------|
| Logo | `✦ LLM Wiki` | 点击 → `/wiki` |
| 导航链接 | 首页、图谱、资料源、队列、导入 | 当前页高亮（active 样式） |
| 搜索框 | 输入即搜，300ms 防抖 | 下拉按类型分组显示结果 |
| 暗色切换 | 🌙 / ☀️ | localStorage 持久化，切换时触发 `document.documentElement` 类切换 |

### 搜索框交互

```
┌─────────────────────────┐
│ 📄 实体 (3)              │
│   python.md             │  点击跳转 /wiki/entities/python.md
│   java.md               │
│ 📦 资料源 (2)            │
│   my-notes/readme.md    │
│ 🕸️ 图谱 (1)             │
│   concepts/ai.md        │
│                        │
│   ── 按 Enter 全局搜索 ──  │
└─────────────────────────┘
```

- **三态**：
  - 空输入：不显示下拉
  - 有结果：按类型分组显示，高亮匹配片段
  - 无结果：显示 "未找到相关页面"
  - 网络错误：显示 "搜索服务暂不可用"

#### 统计卡片

| 卡片 | 颜色 | 数据来源 |
|------|------|---------|

| 实体 | `--success` | page_type=entity 计数 |

### 8.4 迁移路径

**当前模式**：每个路由用 `Path().read_text()` 读取独立 HTML 文件返回

迁移策略：
1. 在 `src/main.py` 中初始化 `Jinja2Templates(directory="src/api/templates")`
2. 创建 `base.html` 作为骨架
3. 逐个模板迁移：先让 `base.html` 可用，再逐个改造子页面
4. 模板继承不影响路由注册方式，改造可增量进行
