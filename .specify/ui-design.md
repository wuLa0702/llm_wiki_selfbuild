# LLM Wiki — UI 设计文档

> **状态**：持续更新。当前版本为 2026-07-18 前端 React + HeroUI 重构后的设计决策。
> **目的**：统一多端（Web / Tauri 桌面端）的 UI 布局与交互规范。

---

## 一、全局布局总规范

### 1. 布局结构（三栏基座）

```
┌──────────┬────────────────┬──────────────────────────────┐
│ 左侧导航  │  中栏（可插拔）  │  右侧主内容区               │
│ (一级菜单) │  (二级面板)     │  (核心内容)                 │
│           │                │                             │
│ 动态宽度   │ 动态宽度        │ 自适应填充                   │
│ 图标+文字  │ 仅知识库页显示  │ Markdown 预览+编辑          │
│ 常驻      │ 其他页隐藏      │                             │
└──────────┴────────────────┴──────────────────────────────┘
```

| 区域 | 宽度 | 特性 |
|------|------|------|
| 左侧导航 | 自适应（fit content） | 图标+文字菜单，不固定死宽度，但不能过宽 |
| 中栏 | 动态（通常 ~320px） | 可插拔，当前仅知识库页显示，其他页隐藏 |
| 右侧主区 | `flex: 1` 填充剩余 | 核心内容展示，支持 Markdown 编辑 |

### 2. 主题与色值（仅深色模式）

```
页面背景:     #121212
面板/侧栏背景: #1A1A1A
卡片/悬浮:    #242424
悬停加深:     #2A2A2A
分割线:       #333333
标题文字:     #FFFFFF
正文:         #D0D0D0
次要文字:     #888888
错误/警告:    #FF5555
主题蓝:       #3684FF
```

### 3. 交互基础规则

- 所有列表项 hover → 背景加深 `#2A2A2A`
- 激活/选中项 → 左侧 3px 蓝色竖线标记 + 背景高亮
- 折叠面板 → 箭头图标控制展开/收起
- 基础交互仅保留：点击、输入、开关、折叠、滚动

## 二、左侧全局导航栏（一级菜单）

### 1. 定位与尺寸

- 位置：页面最左侧，常驻
- 宽度：自适应内容（`fit-content`），图标+文字能展示即可，不设固定宽度
- 背景：`#1A1A1A`
- 分割线：`#333333`

### 2. 内容结构（从上到下）

```
┌──────────────────┐
│ Logo + 标题      │  ← 应用标识
├──────────────────┤
│ 💬 对话          │
│ 📖 原始资料      │  ← 6 个一级菜单
│ 🔍 检索          │
│ 🕸️ 图谱          │
│ ✅ Wiki 检查      │
│ ⚙️ 设置          │
├──────────────────┤
│  ← 底部无其他元素 │
└──────────────────┘
```

### 3. 菜单项规范

- 每项高度 `36px`
- 图标居左，文字左对齐，间距 `8px`
- 激活态：蓝色竖线（左侧 3px）+ `#2A2A2A` 背景
- 无嵌套，平铺一级
- **去掉了「通知」菜单项**（无用）
- **去掉了左下角「返回」按钮**（无意义）

---

## 三、中栏（二级面板）

### 1. 定位与特性

- 位置：左侧导航右侧
- 宽度：动态，当前建议 `~320px`
- **可插拔**：仅「原始资料」页显示，对话/检索/图谱/检查/设置页均隐藏
- 背景：`#1A1A1A`，分割线 `#333333`

### 2. 内容结构

```
┌────────────────────────────────┐
│ 📂 原始资料          [🔄]      │  ← 标题行（无 Tab）
├────────────────────────────────┤
│ 实体 (N)                      │
│  ├─ 页面1                      │  ← 知识库树（按类型分组）
│  └─ 页面2                      │
│ 概念 (N)                      │
│ ...                           │
├────────────────────────────────┤
│ ▶ Raw Sources 原始资料 (N)     │  ← 可折叠，独立展开收起
│  ├─ 📄 文件1.md               │
│  └─ 📄 文件2.md               │
├────────────────────────────────┤
│ N failed tasks          ▼     │  ← 底部队列面板，常驻
│  ● 文件A  失败原因    [↻]     │
│  ● 文件B  失败原因    [↻]     │
└────────────────────────────────┘
```

### 3. 关键约束

- **没有 Tab 切换**——知识库树和原始源文件是上下两块，各自独立折叠展开
- Raw Sources 区域可折叠展开，不与知识库树合并
- 任务队列固定在面板底部，不随列表滚动

---

## 四、右侧主内容区

### 1. 定位与特性

- 自适应填充剩余宽度（`flex: 1`）
- 背景 `#121212`
- 承载核心内容展示与 Markdown 编辑

### 2. 内容

| 页面 | 右侧展示 |
|------|----------|
| 原始资料 - 浏览 | Wiki 页面 Markdown **渲染** |
| 原始资料 - 编辑 | Markdown **编辑**（所有 .md 页面可编辑） |
| 文件选中预览 | 文件内容渲染 |
| 检索 | 搜索输入框 + 结果列表 |
| 图谱 | Canvas 画布 + 顶部工具栏 |
| Wiki 检查 | 断链列表 + 批量操作栏 |

### 3. 操作按钮位置

「原始资料」页的 **刷新 / +导入 / +文件夹** 按钮放在右侧主内容区的**右上角**，不在中栏。

## 五、页面路由清单

| 一级菜单 | 路由 | 中栏 | 右侧 |
|---------|------|------|------|
| 对话 | `/chat` | 无 | 聊天界面 |
| 原始资料 | `/wiki/home` | 知识库树 + Raw Sources + 队列 | Wiki 内容（支持编辑） |
| 检索 | `/search` | 无 | 搜索框 + 结果列表 |
| 图谱 | `/graph` | 无 | Canvas 画布 + 工具栏 |
| Wiki 检查 | `/wiki/audit` | 无 | 断链列表 + 批量操作 |
| 设置 | `/settings/llm` | 设置子导航（4 Tab） | 各 Tab 配置项 |

## 六、设置页

### 1. 布局

左侧 4 Tab 子导航，右侧对应配置项。

### 2. 设置分类

| Tab | 配置项 |
|-----|--------|
| **通用** | 输出语言（中文/English）、主题偏好 |
| **资料监控** | Watcher 启停、轮询间隔（秒）、监控目录路径 |
| **隐私规则** | 敏感词列表（增删）、分类 |
| **维护** | 重建知识图谱、系统重置 |

### 3. API 对照

| 设置 | API |
|------|-----|
| 通用 | `GET/POST /v1/settings` |
| 监控启停 | `POST /v1/watcher/start`, `POST /v1/watcher/stop` |
| 监控状态 | `GET /v1/watcher/status` |
| 监控配置 | `POST /v1/watcher/config` |
| 隐私规则 | `GET/POST/DELETE /v1/privacy/rules` |
| 重建图谱 | `POST /v1/system/reset` |

---

## 七、组件复用规范

- **左侧导航**：全局单例，路由切换仅变更高亮项
- **中栏组件**：仅用于原始资料页，其他页隐藏
- **任务队列**：全局共用，嵌入中栏底部
- **Markdown 编辑器**：右侧内容区可复用组件，支持渲染 + 编辑模式切换

---

## 八、约束记录

1. 深色模式仅一种，不做亮色/暗色切换
2. 所有颜色从 CSS 变量读取，禁止硬编码
3. 左侧导航宽度不固定死，自适应内容
4. 中栏可插拔，不能在所有页面强制显示
5. 知识库树与 Raw Sources 是上下分区，不是 Tab 切换
6. 操作按钮（刷新/导入/文件夹）位于右侧区右上角
7. 所有列表行 hover 统一加深 `#2A2A2A`
8. 激活项左侧 3px 蓝色竖线标记
