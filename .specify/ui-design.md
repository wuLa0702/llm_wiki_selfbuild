### 1\. 全局布局结构（固定三栏基座，全局页面通用）

|区域|位置|宽度占比|固定属性|基础说明|
|---|---|---|---|---|

1. **主题模式**：仅深色模式（暗黑底色）

    - 卡片 / 悬浮面板：`#242424`

    - 分割线：`#333333`

2. **文字层级**

    - 标题文字：纯白色 `#FFFFFF`

    - 正文常规文本：浅灰 `#D0D0D0`

    - 次要说明文字：浅灰偏暗 `#888888`

    - 警告 / 失败文本：红色 `#FF5555`

    - 高亮可点击按钮：主题蓝 `#3684FF`

3. **交互基础规则**

    - 所有列表项 hover：背景色加深 `#2A2A2A`

    - 激活选中项：左侧加蓝色竖线标记 \+ 背景高亮

    - 折叠面板：箭头图标控制展开 / 收起

    - 窗口：标准 Windows Tauri 原生窗口（最小化 / 最大化 / 关闭）

## 四、组件复用规范（Agent 开发强制遵循）

1. **底部失败任务栏**：知识库 / 检索 / 图谱 / 校验页**全部共用同一段 UI 组件**，无需重复开发；

2. **左侧全局导航**：全局单例组件，路由切换仅变更高亮项；

3. **中间面板 Tab 容器**：知识库与文件 Tab 封装为同一个 Tab 切换组件；

4. **列表基础行组件**：文件条目、失败任务、校验项、待审阅项统一封装通用列表 Item，通过传参控制按钮与文案；

5. **深色主题全局变量统一注入**，所有颜色取值从全局 CSS 变量读取，硬编码颜色禁止写死。
