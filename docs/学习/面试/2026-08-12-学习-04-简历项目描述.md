## 3. 版本 B：详细项目经历（简历项目栏，主推版）

```
LLM Wiki 知识编译系统（自研全栈）                             2026.06 - 至今

技术栈：Python · LangGraph · LangChain · FastAPI · ChromaDB · SQLite · React 19 · SSE

项目概述：
  基于 Karpathy LLM Wiki 理念的"知识编译 + 智能问答"系统——区别于传统 RAG 的
  每次查询重新检索，本系统在摄入时用两步 CoT 将原始资料一次性编译为结构化
  Wiki 知识库，查询时由手写 9 节点 LangGraph ReAct Agent 在知识层上导航回答，
  知识随使用累积变厚。完整闭环：摄入→图谱→检索→Agent 对话→前端→打包。

核心贡献：

  1. 手写 LangGraph 状态机 + 三层自纠错
     替代 create_react_agent 手写 9 节点 StateGraph（意图分类/规划/记忆注入/
     审批/工具/质检/反思），在标准 ReAct 循环上叠加三层防御：validate_tool
     （15 步熔断 + 动作去重）→ verify_result（输出质检）→ reflect_node（LLM
     结构化反思修正），对比裸 ReAct 无效工具调用降低约 60%（开发期对比测试）。

  2. 双轨记忆体系 + 混合持久化
     用户驱动 Attention Sink（显式锚定 + 频次检测 + 置信度衰减淘汰）与系统驱动
     结构化 Working Memory（5 槽位增量合并）双轨并行；MemorySaver 运行时 +
     SQLite 冷启动回灌；>40 条消息自动 LLM 摘要压缩，关键信息跨摘要存活；
     30 天闲置会话 LLM 归档降级。

  3. 混合检索 + 知识图谱
     BM25（CJK Bigram 分词 + 标题加权）+ Chroma 384 维向量 + RRF 免调参融合；
     wikilink 解析构建知识图谱，4-Signal 加权关联度 + Louvain 社区发现 +
     洞察引擎（惊喜连接/知识缺口自动发现，纯确定性零 LLM 成本）；
     SHA256 摄入缓存 + 图谱签名缓存，全链路增量优先。

  4. 生产级安全与交互
     路径穿越统一校验真源 safe_path()（工具层与 API 共用）+ 目录隔离
     （raw 只读/wiki 可写）+ LLM 输出白名单校验 + bcrypt 密码门禁；
     风险分级 Human-in-the-Loop（只读自动放行，风险工具 interrupt 审批，
     默认 fail-closed）；SSE 5 事件流式对话，React 19 九页面 SPA；
     8 个 MCP 工具（stdio/HTTP 双模式）供外部 IDE 即插即用。

  5. 工程化交付
     754 后端 pytest（LLM 全 mock）+ 81 前端 + 22 E2E；SQLite 16 表参数化
     查询 + 操作审计；PyInstaller 桌面打包（单实例锁 + 崩溃兜底）；
     223 commits，测试文档齐全。

面试亮点：
  - LangGraph 全栈实战：StateGraph / add_messages reducer / conditional_edges /
    interrupt+Command / checkpointer / astream_events，全部手写理解非调包
  - 安全与工程细节：路径穿越防御、Windows 并发坑、增量计算教训、降级路径设计
  - 诚实短板与规划：向量搜索默认关（依赖体积）、LangSmith 留接口未接、
    SqliteSaver/多 Agent 有明确升级路径
```
