## 一、2026-08 增量情报（今日搜索）

### 1. Agent 不是单一岗位，是 7 个方向（扒 200+ 份校招 JD）

| # | 方向 | 特点 | 本项目匹配 |
|---|------|------|-----------|
| 1 | 模型应用工程师 | 池子最大、门槛最低 | ⭐⭐⭐⭐⭐ |
| 2 | AI Coding 工程师 | 2026 最热新赛道 | ⭐⭐ |
| 3 | Agent 中台/框架开发 | 技术深度型 | ⭐⭐⭐⭐ |
| 4 | Agent 算法/对齐 | 训练侧、门槛最高 | ⭐ |
| 5 | 业务 Agent 工程师 | 垂直场景、重业务嗅觉 | ⭐⭐⭐ |
| 6 | Agent 产品经理 | 非技术岗 | ❌ |
| 7 | Agent 评测/AI Safety | 小众极稀缺 | ⭐⭐ |

### 2. 市场热度数字

- 岗位供需比约 **1:8**，行业缺口约 2.45 万人，年薪中位数约 95 万（媒体口径）
- DeepSeek 2026-06 狂招 36 岗，**80% 岗位提及 Agent**
- 字节校招 1205 个 AI 相关岗（占研发岗 47%）；阿里 AI 岗占比超 60%
- 技术栈出现频率：**LangChain 仍是第一框架（34.3% JD）**，但 LangGraph + MCP 已是生产标配（89% 团队做 Observability）

### 3. 典型 JD 要求（联蔚数科 AI 软件工程师 2-3.5 万/月为例）

- AI-Native 开发思维，深度用过 Claude Code / Cursor / Trae
- 至少精通多数：LangGraph / MCP / Function Calling / Multi-Agent / Browser-use / Reranking / Agentic Workflow
- 三选一方向精通：① RAG 全链路 + Hybrid Search + Rerank ② 爬虫/Computer-Use ③ NLP 核心

### 4. 三轮面试考察内容（面试指南类文章共识）

| 轮次 | 时长 | 考什么 | 本项目对应 |
|------|------|--------|-----------|
| 一面 | 60-90min | 简历项目连环追问，无八股：记忆细节/成本/选型/故障排查/数字 | interview/03 Q1-21 |
| 二面 | 60-90min | 从 0 到 1 设计商用 Agent：模块拆分/任务调度/容错/工具权限/注入防护 | interview/03 Q22-30 |
| 三面 | 30-50min | 赛道判断/差异化/瓶颈预测/带业务排优先级 | interview/03 Q31-35 |

淘汰率：一面刷 ~60%，二面再刷 ~60%，最终录取 5-10%。**第三轮出局主因：简历数据无法验证、聊不出 Trade-off。**

### 5. 企业真正稀缺的 4 种人才（对照自查）

1. **能把 Agent 做稳**：异常处理（重试/间隔/降级）、安全边界（防 Prompt Injection）、幻觉治理 → 本项目：三层自纠错 ✅
2. **能把 Agent 做快**：延迟测量与优化（流式/分层/预热/并行/缓存/降级）→ 本项目：SSE + 增量缓存 ✅（缺压测数据 ⚠️）
3. **能把 Agent 做出差异化**：避开客服/知识库问答/文档助手三大烂大街 → 本项目：知识编译定位 ✅
4. **能把 Agent 做出业务价值**：量化指标（时间从 X 降至 Y、干预率从 A% 降至 B%）→ 本项目：⚠️ 缺业务场景量化，需包装

### 6. 面试减分行为（引以为戒）

- ❌ 回答像营销稿
- ❌ 说不清失败边界（系统何时该停/升级/向用户确认）
- ❌ 没有评测纪律（能跑 demo ≠ 能做系统）
- ❌ 只会讲循环，不讲停止条件/评测/故障恢复
- ❌ 简历堆框架名词（HR 抄模板的典型表现）

## 二、7 月调研摘要（与 08 增量合并后的完整判断）

| 维度 | 结论 |
|------|------|
| 供需 | 基座缩 HC、Agent 爆发；投递量暴涨，热门 Agent 岗竞争 120-180:1 |
| 简历初筛 | AI 初筛淘汰率 65%，无落地项目直接挂 |
| 面试内容 | 从"Transformer 理论"转向"LangGraph 状态管理/记忆分层/审批/容错" |
| 项目门槛 | 线上可访问 + 完整工程部署 + 处理过复杂业务流程（**本项目缺公网部署 ⚠️**） |
| 薪资 | 初级 Agent 开发 50-75w，资深 130-260w，DeepSeek 应届最高 140w（媒体口径） |
| 转型红利 | Java 转 Agent 跳槽薪资上浮 40-70% |

## 三、本项目 vs 岗位要求差距矩阵（现状更新版）

| 岗位硬要求 | 本项目状态 | 动作 |
|-----------|-----------|------|
| LangGraph 实战 | ✅ 手写 9 节点 + 全部核心 API | 无 |
| Checkpoint 持久化 | ✅ MemorySaver + SQLite 混合 | 升级 SqliteSaver（P1） |
| 人工审批 | ✅ interrupt + Command(resume) | 无 |
| 记忆分层 | ✅ Sink + WM + 摘要 + 归档 | 无 |
| 工具权限/安全 | ✅ safe_path + 目录隔离 + 只读工具 | 补 Prompt 注入检测（P1） |
| MCP | ✅ 8 工具双模式 | 统一 Agent 内部工具为 MCP-first（P1） |
| 混合检索 | ✅ BM25 + 向量 + RRF | 向量默认开（装依赖）+ chunk 章节级升级 |
| SSE 流式 | ✅ 5 事件 | 无 |
| **可观测** | ⚠️ LangSmith 零集成 | 3 行 .env 启用（P0，面试前必做） |
| **线上部署** | ⚠️ 仅本地 + 桌面打包 | 自托管 workflow 已写，上云（P0） |
| **并发压测** | ❌ 无压测数据 | 补一个压测报告（P1） |
| 多 Agent | ⚠️ 明确规划未实现 | 讲清"为什么先单 Agent 做深" |

**P0 三件事（面试竞争力排序）**：① LangSmith 接通 ② 公网部署 ③ 数字自证（interview/04 §8）
