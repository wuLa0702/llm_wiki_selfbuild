## 1. A 灵魂层（开场 30 秒 + 必考追问）

### A1. 编译器模式 vs RAG
- **讲法**：RAG 是解释器（每次查询重新分块/检索/拼 prompt），LLM Wiki 是编译器（摄入时一次编译成结构化知识，查询在已编译的知识层上导航，知识越用越厚）。
- **追问接招**：编译错了怎么办（raw/ 不可变基准 + Lint + SHA256 缓存）· 为什么不用 RAG（定位是知识沉淀不是问答机器人）。
- **证据**：`interview/02` 亮点 1 · `docs/rag-wiki-comprehensive-comparison.md`
- **风险点**：别把"编译器"讲成噱头，要能落到"编译产物 = wiki/ 页面 + wikilink 图谱 + DB 元数据"的具体结构。

### A2. 手写 LangGraph StateGraph，不用 create_react_agent
- **讲法**：标准循环插不进自定义逻辑（自纠错、审批、记忆注入都要在特定位置挂节点），手写才能精确控制 9 条边的走向；手写也证明真正理解 add_messages reducer / conditional_edges / interrupt。
- **追问接招**：9 节点拓扑背诵（intent → agent → extract_wm → wm_eviction → validate_tool → approve → tools → verify_result → reflect_node → summarizer）。
- **证据**：`interview/01` §3.3 九节点图 · `interview/02` 亮点 3 · 代码 `src/agent/planning/graph.py`
- **风险点**：手写是双刃剑——面试官可能深入问 reducer 行为、条件边返回值匹配，必须能徒手画出节点图。

## 3. C 设计决策层（15 个"为什么"，挑 5-6 个讲）

完整表在 `interview/01` §5（编译器模式 / 两步 CoT / 手写图 / 自纠错 / 双轨记忆 / 混合持久化 / 风险 HITL / 路径安全唯一真源 / 增量优先 / 隐私生成全量+按标记门禁 / Flash 默认 / SSE / 单 Agent 边界 / 3 只读工具 / Windows 细节）。

**面试最常被问的 5 个**（优先练）：

1. **为什么两层 CoT 摄入** — 先计划再执行；单步会遗漏实体/忽略关联/跳过矛盾；失败降级 ingest_simple 保闭环。（02 亮点 2）
2. **为什么路径安全收敛到唯一真源** — `safe_path()` 统一校验，工具和路由共用，防穿越；工具调用必须前缀校验。（`src/tools/path_utils.py`）
3. **为什么 DeepSeek Flash 默认** — 评分矩阵：成本差 12 倍 vs 质量差 1-3 分；Pro 兜底。（01 决策 11 · `docs/project-experience-summary.md` §二.6）
4. **为什么增量优先** — 高频路径必须增量（SHA256 摄入缓存 + 图谱签名缓存 + relevance 增量），全量 N² 是性能炸弹。（01 决策 9 · 经验汇总 §二.4）
5. **为什么单 Agent 边界明确** — 单 Agent 做深，多 Agent 是下一步不硬塞；基础设施可复用。（01 决策 13）
