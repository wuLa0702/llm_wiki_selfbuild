## 面试前使用流程

- **T-3 天**：过一遍 01（恢复完整印象）→ 02（背 11 个亮点话术）→ 07（画 5 棵树）
- **T-1 天**：03 一面 Q1-21 脱稿 80% → 06 代码块过一遍 → 08 挑 3 个坑练五段式故事
- **T-1 晚**：03 自测清单逐项打勾；徒手画 9 节点图 + ingest 两步图 + 5 棵树
- **T-0 当天**：只复习 01 §8 电梯陈述 + 02 速查表

## 维护规则

1. **新问题** → 追加到 03，按"轮次 + 编号"递增，不删旧题号（与 rag-wiki 文档编号规则一致）
2. **新亮点/话术** → 追加到 02，保持"30 秒讲法 + 追问接招"格式
3. **简历改动** → 改 04 后同步改 `docs/rag-wiki-comprehensive-comparison.md` §8.2
4. **数字变更** → 改 01 §6 现状速览，数字必须能指到证据（测试/日志/文档）
5. **新调研** → 追加到 05 增量小节，注明日期和来源链接
6. **新坑** → 追加到 08 导航表 + 正文，按五段式模板写
7. **代码演进** → 06 更新代码段 + 行号；07 树形图同步
8. 文件头元信息（日期/数量）每次更新同步改
