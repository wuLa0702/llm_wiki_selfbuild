## §1 总（30s）

> "WikiGraph 是 RAG 没有的维度：页面编译后自带 `[[wikilinks]]` 互链，我用**确定性算法**（非 LLM）解析成页面关系图——4-Signal 关联度 + Louvain 社区聚类 + 洞察提取，前端可视化成可缩放/过滤的图谱。"

## §2 分（60-90s）

**① 为什么用确定性算法而非 LLM**：
- 图构建是纯结构计算（正则解析 wikilinks + 信号加权），**不烧 LLM token、可缓存、可复现**
- 4-Signal：互链/共现/类别/路径四信号加权 → 关联度

**② 图的用途**：
- **查询扩展**：三角定位里图邻居扩展语义（"哪些页面相关"）
- **社区聚类**：Louvain 找出主题簇 → 回答"这堆资料讲了什么主题"
- **洞察**：跨页面关系洞察（`/v1/insights`）

**③ 工程化**：`graph_cache` 表缓存计算结果；Ingest 后失效重建；图谱可视化（抽屉/缩放/社区过滤）

## §3 流程图

```
wiki_pages → 正则解析 [[wikilinks]] → page_links
  → 4-Signal 加权 → 关联度矩阵
  → Louvain 社区聚类 → 洞察
  → graph_cache 缓存 → /v1/graph + /v1/communities + /v1/insights
```

## §4 总（20s）

> "WikiGraph 把'哪些文档相关'从黑盒变成了**显式可查的图**——这是 wiki 存储相对 RAG 的独特价值，也是前端图谱可视化的数据源。"
