## §1 接口总览

接口面集中在 4 大域 + 若干管理域，前端主要对接对话/图谱/管理页：

| 域 | 前缀 | 接口数 | 说明 |
|----|------|--------|------|
| 对话 | `/v1/agent/*` | 11 | 流式对话 + 会话 CRUD + 工具/模型列表 |
| 图谱 | `/v1/graph|communities|insights` | 3 | WikiGraph 可视化数据 |
| 导入 | `/v1/ingest*` | 11 | 导入 + 队列管理 |
| 查询/搜索 | `/v1/query|search` | 2 | 问答 + 搜索 |
| 管理 | auth/pages/lint/purpose/sources/models/privacy/system/settings/watcher | ~35 | 鉴权/页面/质量/目的/源/配置 |

## §2 通用约定

- **路径前缀**：业务接口 `/v1/`；静态 UI `/wiki/*`、`/`、`/health` 不前缀
- **响应体**：Pydantic 模型（`src/models/`），字段 snake_case
- **鉴权**：可选密码门（PasswordManager，bcrypt + 内存 token TTL 24h）；`/v1/auth/*` 控制
- **CORS**：开发本地前端 + 中间件 X-Request-ID

## §4 SSE 流式对话协议

**端点**：`POST /v1/agent/chat`（无状态）｜ `POST /v1/agent/chat/session`（持久化）
**格式**：`data: {json}`（每行一个事件，`\n\n` 分隔），media_type `text/event-stream`

**事件类型**（`type` 字段）：

| type | 含义 | 关键字段 |
|------|------|----------|
| `token` | LLM 逐 token 输出 | content |
| `tool_start` | 工具开始 | tool |
| `tool_end` | 工具结束 | tool / output |
| `tool_approval_needed` | 需要人工审批 | tool / approval_id |
| `intent` | 意图识别结果 | intent |
| `summarize` | 上下文压缩 | summary |
| `done` | 本轮完成 | 会话/用量汇总 |
| `error` | 错误 | message |

**审批流程**：风险工具 → 服务端 `tool_approval_needed` → 前端弹窗 → 用户回传 approval（`/v1/agent/chat` 请求体带 `approval`）→ `Command(resume=...)` 恢复。

## §5 错误码

| code | HTTP | 含义 |
|------|------|------|
| `INTERNAL` | 500 | 未捕获内部错误 |
| `THREAD_NOT_FOUND` | 404 | 会话不存在 |
| `NO_USER_MESSAGE` | 400 | 空用户消息 |
| 其余 | 400/404/403 | 参数/不存在/权限（`{"error","code"}` 结构）|
