## §1 功能清单（10 域）

| # | 功能域 | 状态 | 核心模块 | 说明 |
|---|--------|------|----------|------|
| 1 | Wiki 编译（Ingest）| ✅ | `core/compiler/wiki_compiler.py` | 非结构化资料 → 结构化 wiki 页面：两步 CoT + 结构化输出 + SHA256 缓存 + 重试降级 |
| 2 | Agent 对话 | ✅ | `agent/planning/graph.py` | 单 Agent StateGraph：意图 → 推理 → 记忆 → 审批 → 工具 → 自修正 → 摘要 |

| 4 | 记忆体系 | ✅ | `agent/memory/` | AttentionSink（锚定/衰减）+ WorkingMemory（槽级合并）+ summarizer（压缩）|
| 5 | WikiGraph 图 | ✅ | `core/graph/graph.py` | [[wikilinks]] 解析 + 4-Signal 关联度 + Louvain 社区 + 洞察 |
| 6 | 查询问答 | ✅ | `core/query/` | 三角定位：SQLite + BM25 + 图扩展 + index.md 兜底（非 RAG）|
| 7 | 搜索 | ✅ | `core/search/` | BM25/vector/hybrid 三模式；向量默认关、自动降级 BM25 |
| 8 | 质量检查（Lint）| ✅ | `core/lint/linter.py` | wiki 页面质量校验 + 自动修复 |
| 9 | 成本控制 | ✅ | `core/pricing.py` | Token 用量追踪 + 模型价格管理 + 隐私标记 |
| 10 | 打包部署 | ✅ | PyInstaller + path_resolver | EXE 打包 + 路径 %APPDATA% 自适应 + self-hosted workflow |

## §3 数据表（SQLite）

**wiki.db（schema.py，领域数据）**：

| 表 | 用途 |
|----|------|
| `wiki_pages` | 编译后的 wiki 页面（内容/标题/分类/置信度）|
| `page_links` | 页面间 [[wikilinks]] 关系 |
| `graph_relevance` / `graph_cache` | 图关联度 + 社区缓存 |
| `ingest_cache` / `ingest_queue` | 导入 SHA256 缓存 + 队列状态 |
| `operation_log` | 操作审计 |
| `privacy_rules` / `privacy_categories` | 隐私标记与访问控制 |
| `token_usage_log` / `model_pricing` | Token 用量 + 模型单价 |
| `wiki_settings` / `model_configs` | 设置 + 模型配置 |
| `lint_cache` | 质量检查缓存 |

**agent_persistence.db（store.py，会话数据）**：`agent_threads`（消息/attention_sinks/working_memory/archive_summary）、`thread_messages`、`thread_entities`、`global_entities`、`agent_feedback`
